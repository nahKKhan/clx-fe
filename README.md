# clx-fe

울산 CLX 회전기계 설비 모니터링·진단·정비 업무를 연결하는 프론트엔드 프로토타입입니다. React와 Vite를 사용하며, 엔지니어·정비 담당자·설비 관리 부서의 작업 흐름을 제공합니다.

## 로컬 실행

Node.js 22.12 이상과 npm이 필요합니다.

```bash
npm ci
npm run dev
```

터미널에 표시되는 주소를 브라우저에서 엽니다. 기본 포트가 사용 중이라면 다음처럼 포트를 지정할 수 있습니다.

```bash
npm run dev -- --host 127.0.0.1 --port 5174
```

## 화면과 주요 기능

| 주소 | 업무 공간 | 흐름 |
| --- | --- | --- |
| /#home | 통합 현황 | 설비·알람 현황 확인 |
| /#engineer | 현장 설비 엔지니어 | 설비 현황 → 설비 확인 → 센서 확인 → 정비 계획서 |
| /#maintenance | 정비 담당자 | 인계 현황 → 계획 확인 → 점검·조치 → 보고서 |
| /#manager | 설비 관리 부서 | 제출 현황 → 보고서 검토 → 최종 판단 |

- 중요도·긴급도 매트릭스, 설비 목록 검색과 점 강조 연동
- 대표 센서 트렌드 및 최근 1시간·30분 기간 선택
- 진단 근거와 가상 참고 사례 확인, 계획서 편집·전달
- 실제 점검·조치 기록과 보고서 구성·편집·TXT 다운로드
- 기록 변경 시 오래된 보고서 제출 차단, 수정 제안 비교·적용·취소
- 보고서 수정·반려·재제출, 최종 의견과 승인 이력 보존
- 우측 Copilot 슬라이드 패널, 닫기·바깥 클릭·Esc 지원
- 모바일 화면과 키보드 탐색 지원

엔지니어가 계획서를 전달하면 정비 담당자의 인계 목록에 표시되고, 정비 담당자가 보고서를 제출하면 관리 부서에서 검토할 수 있습니다.

## 빌드와 미리보기

```bash
npm run build
npm run preview
```

빌드 결과는 dist/에 생성됩니다. node_modules/와 dist/는 Git에서 제외합니다.

## 데이터와 구현 범위

- 가상 설비 16대와 설비별 대표 센서 1종을 사용합니다.
- 작업·대화 기록은 브라우저 localStorage의 plant-issues-v6에 문제별로 저장됩니다.
- 같은 브라우저의 같은 주소에서만 기록이 공유됩니다. localhost와 127.0.0.1, 서로 다른 포트는 별도 저장 공간입니다.
- 역할 선택은 데모 화면 전환이며 실제 로그인·권한 제어가 아닙니다.
- 실제 설비·실시간 센서·백엔드·LLM·RAG·작업 지시 시스템 연동은 구현하지 않았습니다.
- Copilot은 키워드 기반 예시 응답을 제공합니다. 계획서·보고서의 일부 추가 요청을 지원하며, 제안은 검토 후 적용합니다.
- 매뉴얼·참고 사례·상태 및 우선순위 기준은 화면 검토용 예시입니다. 실제 설비 안전 기준을 의미하지 않습니다.
